# 设置：新旧入口对照表

2026-11-24 按霜霜的要求重排（“设置页太乱，分门别类做好，参考 dsh-Go”）。
规矩：**一级页只放入口**（图标 + 名称 + 右边一句当前状态 + 箭头）；开关、输入框、选择都在二级页；一类东西只在一处。
逐项检查的测试：`test/settings_map_test.dart`。共用的“组 / 行”部件和尺寸：`lib/ui/settings_widgets.dart`。

## 新结构

| 组 | 入口（一级页的行） | 点开是什么 | 里面有什么 |
| --- | --- | --- | --- |
| （顶部概况卡） | 模型块 / 运行环境块 | 模型与渠道 / 运行环境 | 只读状态：新对话用的模型、余额或额度进度、运行环境装没装 |
| 模型 | 模型与渠道 | `ChannelsScreen` | 〔新对话用哪个模型〕沿用上次 / 固定默认；〔渠道〕列表；添加渠道 → 选服务商 → 渠道编辑（连接、模型） |
| 模型 | 额度与余额（只有 DeepSeek 官方渠道才出现） | 1 个渠道：`QuotaScreen`；多个：先选渠道 `QuotaChannelsScreen` | 余额、已用、设置 / 修改上限、从现在重新算、取消上限、怎么算的 |
| Agent | 权限与执行 | `AgentBehaviorScreen` | 〔权限〕新对话的权限；〔执行〕连续执行多少步后问我、上下文快满时自动压缩 |
| Agent | 个性化 | `PersonalizeScreen` | 〔个人偏好〕；〔Agent 预设〕列表、新建、编辑、复制、设为默认、删除 |

| 能力 | 联网搜索 | `WebSearchSettingsScreen` | 〔搜索服务〕地址、Key、保存；〔测试〕搜一次试试 |

| 能力 | 记忆（2026-11-25 新增） | `MemorySettingsScreen` | 〔记忆〕让 Agent 使用记忆；〔自动整理〕每轮结束后自动整理（默认关，会多花一次模型调用）；〔全局记忆〕〔这个项目的记忆〕条目列表，点开看 / 改 / 删、新增一条；〔管理〕撤销最近一次改动、清空 |
| 能力 | 自动化任务 | `AutomationListScreen` | 原样 |
| 界面 | 对话显示 | `ChatDisplayScreen` | 〔新对话〕开场建议；〔回复里〕用量、思考过程 |
| 界面 | 外观 | `AppearanceScreen` | 〔颜色模式〕跟随系统 / 浅色 / 深色；〔主题〕浅色主题、深色主题两行，点开各是一页主题列表（`ThemePickScreen`，单选，点了立刻生效；2026-11-26 加，现在只有“默认浅色”“默认深色”和用户自己的主题，新建 / 编辑 / 导入导出的界面还没做）；〔代码字号〕10–24、默认 14，可恢复默认（2026-11-25 加；代码区域里双指捏合改的是同一个值；聊天里的改动对比、步骤详情、完整输出、后台日志跟着它走、小一号） |

## 旧位置 → 新位置

| 旧位置 | 新位置 | 变没变 |
| --- | --- | --- |
| 概况卡 · 模型和额度进度 | 概况卡 · 模型块（整块可点，进模型与渠道） | 样子收紧，内容不变 |
| 概况卡 · 蓝字“管理模型 / 添加模型” | 概况卡模型块整块可点；另有 模型 › 模型与渠道 | 蓝字去掉 |
| 概况卡 · 蓝字“设置额度上限 / 额度上限” | 模型 › 额度与余额 | 蓝字去掉，只留一处入口 |
| 概况卡 · 运行环境状态 + 蓝字“运行环境” | 概况卡 · 运行环境块（整块可点）；另有 运行与打包 › 运行环境 | 没打开工作区现在也能进 |
| AI › 模型与渠道 | 模型 › 模型与渠道 | 不变 |
| AI › 个性化 | Agent › 个性化 | 不变 |
| AI › 额度上限 ·（每个 DeepSeek 渠道一行） | 模型 › 额度与余额（多个渠道时先进一页选渠道） | 一级页只占一行 |
| AI › 项目规则 | 当前工作区 › 项目规则 | 从全局的组里分出来，组标题写明是哪个工作区 |
| 能力 › 新对话的权限（点开弹层） | Agent › 权限与执行 ›〔权限〕新对话的权限 | 多一层；弹层和“完全权限”确认不变 |
| 能力 › 子代理与团队 | Agent › 子代理与团队 | 不变 |
| 能力 › 自动化任务 | 能力 › 自动化任务 | 不变 |
| 能力 › 联网搜索 | 能力 › 联网搜索 | 不变；“搜一次试试”从按钮改成〔测试〕组里的一行 |
| 能力 › 技能 | 能力 › 技能 | 不变；页内分〔这个工作区〕〔全局〕两组 |
| 对话 › 在新对话里显示开场建议（开关） | 界面 › 对话显示 ›〔新对话〕 | 多一层 |
| 对话 › 在回复下方显示用量（开关） | 界面 › 对话显示 ›〔回复里〕 | 多一层 |

## 没放进设置、留在原处的

| 东西 | 在哪 | 为什么不搬 |
| --- | --- | --- |
| GitHub 打包配置（仓库、令牌等） | 打包页里的表单 | 在 `lib/build/`，不在这次能改的范围；它只在打包时用 |
| 低余额提醒线 | 对话页用量弹层的余额卡 | 在 `lib/ui/usage_ui.dart`，不在这次能改的范围 |
| 终端的中文输入、运行环境的下载源和兼容模式 | 终端页 / 运行环境页 | `lib/runtime/**` 另一路在改 |
| 智能体团队的任务板 | 对话页右上角菜单 | 是干活的地方，不是设置；开关在 Agent › 子代理与团队 |
| 这段对话的权限、模型、预设 | 对话页输入框“＋”面板和菜单 | 是单段对话的选择；设置里只管“新对话默认” |
| 收藏的消息 | 侧边栏“对话”分组里的“收藏的消息”；对话页右上角菜单里也有一项 | 是内容，不是设置。按工作区存在 `.lopicode/favorites.json`；页面是 `FavoritesScreen`（`lib/ui/favorites_screen.dart`）。收藏 / 取消收藏在每条消息下面的“⋯”里 |
| 单条消息的操作（复制、重试、编辑、分支、收藏、分享、删除） | 对话页每条“我的消息”和“Agent 的回复”下面的一排小图标：我的消息常驻“复制、编辑、⋯”，Agent 回复常驻“复制、重试、⋯”；“从这里分支”“重新发送”在“⋯”里 | 登记表在 `lib/ui/message_action_bar.dart` 的 `kMessageActions`；重试 / 编辑 / 分支的动作在 `lib/ui/message_branch_actions.dart`，规矩在 `lib/session/message_branches.dart`，设计见 [chat-branches.md](chat-branches.md)。Agent 正在回复时不能删除、重试、编辑 |
| 分支和旧版本 | 侧边栏“对话”列表里带“分支”/“旧版本”小标签的对话；对话页右上角菜单“回到原对话：…”；原对话那条消息下面的分叉图标（“这里分出去的对话”） | 是内容，不是设置。分支＝复制出来的一段新对话；重试 / 编辑前的内容另存成“旧版本”。出处记在 `.lopicode/chats.json` 每段对话的 `from` 里 |
