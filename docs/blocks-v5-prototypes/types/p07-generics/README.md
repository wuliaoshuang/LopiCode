# p07-generics

p07 泛型函数：类型实参全靠调用处推断，用的人从来不用写〈…〉。三个函数的签名都标全了（泛型函数必须标）。

## 里面有什么

- `prog.lc`：源程序（S 表达式写的语法树；参数写成 `(名字 类型)` 就是标了类型，只写名字就是没标）
- `types.txt`：**手工**按规则推出来的每个函数签名、每个变量的类型
- `expect.txt`：**事先写下**的预期输出
- `main.js`、`main.py`、`go/main.go`、`Main.java`：按映射表手写的四种语言（Go、Java 用的是原生类型）

## 怎么跑

```
cd ..  &&  ./run_all.sh p07
```

## 跑出来什么

四种语言的输出逐字节相同，都等于 `expect.txt`：

```
第一个 3
空的第一个 没有
最大整数 9
最大小数 1.5
最大文字 😀
a=1;b=2
```

`infer.py` 自动推断的结果和 `types.txt` 一致（不看行的先后）。
