# e03-cases-records

e03 故意写错：“分情况”没写全、记录缺东西 / 多东西 / 想改。

## 里面有什么

- `prog.lc`：故意写错的源程序，每一处错在行尾注明
- `errors.txt`：**手工**写下的、应该报出来的每一条（编号＋在哪个函数＋提示原文）

这个目录只过检查、不生成代码（有错的程序本来就不让生成）。

## 怎么跑

```
cd ..  &&  ./run_all.sh e03
```

## 跑出来什么

`infer.py --errors` 报出来的和 `errors.txt` 逐字节相同：

```
T03 名：“分情况”还少了：黄（或者加一个“其余”）
T08 面积：「形状」里没有「方」
T04 主：新建「点位」还缺：y
T04 主：「点位」没有「z」这一项
T10 主：记录「点位」建好以后不能改，用“复制并改”
T01 主：「点位」的「x」要小数，放进来的是文字
T08 主：点位没有「z」这一项
```
