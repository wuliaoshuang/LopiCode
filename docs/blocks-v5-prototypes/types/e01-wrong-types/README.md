# e01-wrong-types

e01 故意写错：类型对不上的几种最常见情况。每一处错在右边注明。

## 里面有什么

- `prog.lc`：故意写错的源程序，每一处错在行尾注明
- `errors.txt`：**手工**写下的、应该报出来的每一条（编号＋在哪个函数＋提示原文）

这个目录只过检查、不生成代码（有错的程序本来就不让生成）。

## 怎么跑

```
cd ..  &&  ./run_all.sh e01
```

## 跑出来什么

`infer.py --errors` 报出来的和 `errors.txt` 逐字节相同：

```
T01 主：「重复」的第 2 个参数要整数，放进来的是文字
T06 主：减法的两边要数字，这里有一边是文字
T09 主：这里要“是/否”，放进来的是整数
T07 主：「重复」要 2 个参数，给了 1 个
T01 主：「半」是整数，放进来的是小数
T06 主：“整除”的两边要整数，这里有一边是小数
```
