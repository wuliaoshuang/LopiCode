# 类型系统的验证原型（积木第 5 版 · B 部分）

配套文档：`../../blocks-v5-parts/B-type-system.md`。这里的东西**只为验证设计**，不是产品代码，产品不引用它。

## 一键全跑

```
./run_all.sh            # 全跑，结果写进 RESULT.txt（1.5 核的机器上约 3 分钟）
./run_all.sh p03 p07    # 只跑名字以这些开头的目录
```

需要：Node、Python 3.12+、Go（只用标准库，不联网）、JDK 21。没有用到、也没有安装任何别的东西。
临时文件都在 `/tmp/v5-B/`。TypeScript 和 PHP 没跑（机器上没有 tsc 和 php）。

## infer.py（推断规则的原型，约 1105 行 Python）

读 `prog.lc`，自动推出每个函数的签名、每个变量的类型，报 T 开头的错误。`run_all.sh` 拿它的结果去对手写的 `types.txt` / `errors.txt`。

**覆盖了的规则**：字面量；整数 / 小数的运算结果类型和“整数自动当小数用”；变量类型＝所有赋值合并；返回类型＝所有“返回”合并（含递归）；
没标类型的参数＝所有调用处实参合并（反复算到不再变）；匿名函数没标的参数看上下文、没有上下文算任意；泛型调用先看普通参数再看匿名函数、
类型变量变宽后重看一遍；空列表 / 空字典 / 没写〈…〉的泛型类，从后面的“加项”“存”“方法调用”定下来；
可空的收窄（如果 / 否则、提前返回、且 / 或 / 非、被改以后失效、带不带进匿名函数）；记录、枚举、变体、分情况写没写全；
类、继承、接口、泛型类；类⊔类＝最近公共父类或唯一共同接口；任意和确定类型互相能放；一处错只报一句。
报得出的错误：T01–T12、T16（T11 只查“接口的方法有没有、返回类型对不对”）。

**没覆盖的**（文档里有规则，原型没做）：用“是 某类”判断以后的收窄；元组、可选参数、剩余参数；库的导出与“导出函数必须标全”（T13）；
“往任意里的列表加东西”的提醒（T14）；向下转型不可能（T15）；继承相关的 T17、T18；稍后的结果〈T〉；
“试着做”里面赋值对收窄的精确影响（原型按保守处理）；文件之间的类型。
它也**不生成代码**：四种语言的程序是按映射表手写的。
