# p16-any-containers

p16（第二轮新加）确定类型的列表 / 字典和“任意”之间怎么过：
装进任意 ＝ 拍一份快照；从任意取回成 列表〈整数〉 ＝ 逐项检查、得到一份新的；
当成 列表〈任意〉 ＝ 只看“是不是列表”，还是同一个。
标了类型的：装、装2（任意）。其余没标。

## 里面有什么

- `prog.lc`：源程序（S 表达式写的语法树；参数写成 `(名字 类型)` 就是标了类型，只写名字就是没标）
- `types.txt`：**手工**按规则推出来的每个函数签名、每个变量的类型
- `expect.txt`：**事先写下**的预期输出
- `main.js`、`main.py`、`go/main.go`、`Main.java`：按映射表手写的四种语言（Go、Java 用的是原生类型）

## 怎么跑

```
cd ..  &&  ./run_all.sh p16
```

## 跑出来什么

四种语言的输出逐字节相同，都等于 `expect.txt`：

```
原来的有 4 项，装进任意的是 [1,2,3]
任意里的 [1,2,3,"五"]
不行：列表的位置 3：这里要整数，拿到的是文字
取回来的 1,2,3,9，任意里的 [1,2,3]，原来的有 4 项
字典 {"a":1.5}，原来的有 2 项
```

`infer.py` 自动推断的结果和 `types.txt` 一致（不看行的先后）。
