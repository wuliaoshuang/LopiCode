# e04-generics-classes

e04 故意写错：泛型的约束、接口没实现全、列表里放错东西、空列表看不出放什么、匿名函数参数个数不对。

## 里面有什么

- `prog.lc`：故意写错的源程序，每一处错在行尾注明
- `errors.txt`：**手工**写下的、应该报出来的每一条（编号＋在哪个函数＋提示原文）

这个目录只过检查、不生成代码（有错的程序本来就不让生成）。

## 怎么跑

```
cd ..  &&  ./run_all.sh e04
```

## 跑出来什么

`infer.py --errors` 报出来的和 `errors.txt` 逐字节相同：

```
T11 猫：「猫」说自己是「会叫」，但是没有「叫」这个方法
T05 头：T 没有说明“能比大小”，不能比
T05 主：「最大」要的是能比大小的东西（数字或文字），点位不能比大小
T01 主：往列表里加的东西要整数，放进来的是文字
T07 主：这里要一个收 1 个参数的函数，给的收 2 个
T12 主：「空的」里放什么还看不出来，先当成“任意”
```
