# e02-nullable-misuse

e02 故意写错：可能是空的值，没判断就用。也放了几处写对的，确认不会乱报。

## 里面有什么

- `prog.lc`：故意写错的源程序，每一处错在行尾注明
- `errors.txt`：**手工**写下的、应该报出来的每一条（编号＋在哪个函数＋提示原文）

这个目录只过检查、不生成代码（有错的程序本来就不让生成）。

## 怎么跑

```
cd ..  &&  ./run_all.sh e02
```

## 跑出来什么

`infer.py --errors` 报出来的和 `errors.txt` 逐字节相同：

```
T02 明年：加法的一边可能是空，要先判断“不是空”才能算
T02 找：「找」说好返回整数，这里返回的可能是空
T02 主：「加倍」的第 1 个参数要整数，「v」可能是空，要先判断“不是空”
T02 主：比大小的一边可能是空，要先判断“不是空”才能比
T02 主：乘法的一边可能是空，要先判断“不是空”才能算
```
