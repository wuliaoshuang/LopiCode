# p10-any

p10 “任意”和确定类型的边界：任意 → 确定类型要过一次检查（转），不对就抛错；确定类型 → 任意随便放。
标了类型的：读用户 的参数（任意）和返回值，主程序里的 好、n、装、坏。

## 里面有什么

- `prog.lc`：源程序（S 表达式写的语法树；参数写成 `(名字 类型)` 就是标了类型，只写名字就是没标）
- `types.txt`：**手工**按规则推出来的每个函数签名、每个变量的类型
- `expect.txt`：**事先写下**的预期输出
- `main.js`、`main.py`、`go/main.go`、`Main.java`：按映射表手写的四种语言（Go、Java 用的是原生类型）

## 怎么跑

```
cd ..  &&  ./run_all.sh p10
```

## 跑出来什么

四种语言的输出逐字节相同，都等于 `expect.txt`：

```
小明 13 a/b
装进再取出 42
任意相加 41.5
任意的样子 {"名字":"小明","年龄":12,"标签":["a","b"]}
不行：这里要整数，拿到的是文字
不行：这里要文字，拿到的是数字
不行：这里要整数，拿到的是 12.5
不行：这里要字典，拿到的是文字
不行：这里要文字，拿到的是数字
```

`infer.py` 自动推断的结果和 `types.txt` 一致（不看行的先后）。
